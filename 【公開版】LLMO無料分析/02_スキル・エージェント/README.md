# 02_スキル・エージェント

Claudeが読む作業指示書（スキル）と、その参照資料。**現場メンバーが普段開く必要はありません**（編集・改善時のみ）。

| パス | 役割 |
|---|---|
| `llmo-registration/SKILL.md` | 登録フェーズ：ヒアリング確認→ツール登録→プロンプト洗い出し |
| `llmo-free-report/SKILL.md` | アウトプットフェーズ：4分析データ取得→分析→pptx生成 |
| `references/` | 分析の考え方（当社スタンス・無料版スコープ／ファネルKPI／ブランド差分／サイテーション／サイト診断／プロンプト洗い出し観点） |
| `templates/` | 分析サマリーの体裁／Gemini in Chrome用データ抽出プロンプト（配布用） |

## 仕組みメモ
- ルートの `CLAUDE.md` が依頼内容→スキルのルーティングを定義
- ルートの `.claude/skills/` に同名の薄いラッパーがあり、Claude Codeのスキル自動認識にも対応（本体はこのフォルダ、二重管理しない）
- スキルを改善したら、この配下の SKILL.md を直接編集すればよい（ラッパーは触らない）
