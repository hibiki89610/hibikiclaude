# ブランド差分分析（/brand-listening × ヒアリング）

レポートの「現状分析②」。**ツールの観測（🔵）とヒアリングの“ありたい姿”（🟡）を突き合わせる**のが肝。

## ツールから読むもの（🔵）
- ヘッダの数値：ポジション方針◯軸／意図どおり n/N／要対策◯件／強めたい認識◯・抑えたい認識◯
- マップ/一覧：認識軸ごとに「自社が主な勝者／接戦／競合が支配」
- **強い認識**＝自社が勝者の軸＋勝率の高い競合比較＋ポジティブに語られるテーマ（モニタリングと併読）
- **弱い認識**＝競合支配・圏外の軸。「土俵が違う」軸（そもそも狙わない領域）は区別して書く

## ヒアリングから使うもの
ヒアリングシート②「ブランド定義＝AIに何者として覚えてもらいたいか」と⑤「プロンプトの方向性」。
これが**ありたい認識**。無い場合は差分分析ができないので、メンバー経由でクライアントに確認する。

## 差分の出し方（🟡）
| パターン | 意味 | 方向性の型 |
|---|---|---|
| ありたい×現状も強い | 維持・拡張 | その軸の第三者言及を厚くして防衛 |
| ありたい×現状は圏外 | **最優先ギャップ** | 認識をゼロから作る（事例・解説・第三者言及の集中投下） |
| ありたくない×現状強い | 認識の歪み | 抑えたい認識。文脈の上書きが必要 |
| ありたい認識が曖昧 | 定義の問題 | ブランド定義の見直し（CEP分析・n1分析・カテゴリコンセプト開発の提案文脈） |

gap欄は「ありたい姿 → 現状 → 埋める優先方向」を2点以内で書く。
**ブランド定義そのものが弱いと診断した場合は、レポート最後のご支援メニュー（ブランド支援バンド）につながる一言を入れる。**
