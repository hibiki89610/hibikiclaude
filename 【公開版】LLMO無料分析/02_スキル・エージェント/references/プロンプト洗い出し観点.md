# 追加プロンプトの洗い出し観点（登録フェーズ用）

ツールが自動生成するプロンプト候補は「ブランド定義」起点。以下の観点で穴を見つけ、追加候補を理由付きで提案する。
**無料分析は合計20〜40本が目安。**「多く測る」より「クライアントの商流に効く質問を測る」を優先する。

## 1. ジャーニー網羅チェック
| 段階 | 質問の型 | 例 |
|---|---|---|
| 情報収集 | 選び方・やり方・相場 | 「〇〇の選び方を教えて」「〇〇の費用相場は？」 |
| ブランド想起 | おすすめ・ランキング・比較一覧 | 「おすすめの〇〇は？」「〇〇を比較したい」 |
| 比較検討 | 自社 vs 競合の一騎打ち | 「AとBはどちらがいい？」「Aからの乗り換え先は？」 |
| 意思決定 | 指名＋不安つぶし | 「Aの料金は？」「Aの評判・解約・事例は？」 |

各段階に最低2〜3本。**比較検討★（最重要）**が薄いことが多いので必ず確認。

## 2. ヒアリング⑤（プロンプトの方向性）との突き合わせ
クライアントが「この文脈で出たい」と言った領域・ユースケース・ターゲット（例：B2B/B2C、業界、地域）が
プロンプト文面に反映されているか。汎用語だけでなく**クライアントの商流の言葉**（「〜を外注したい」「〜を内製化したい」等）を入れる。

## 3. 競合対称性
- 主要競合それぞれに「自社 vs 競合」プロンプトがあるか
- 「（競合名）からの乗り換え先でおすすめは？」があるか（乗り換え文脈は受注に直結）
- 競合には汎用AI（ChatGPT等）や隣接カテゴリも含まれ得る。ヒアリング④に無くても、想起で競合しそうなものは🟡提案する

## 4. 意思決定の不安つぶし
料金／初期費用／解約・契約期間／評判・口コミ／導入事例（業界別）／サポート／セキュリティ・著作権など業界固有の不安。
**AIが答えられない質問＝公式情報の穴**なので、弱そうなテーマこそ計測に入れる。

## 5. ブランド定義との整合
「AIに何者として覚えてもらいたいか」の言葉（カテゴリ名・強み軸）が、想起系・比較系の両方のプロンプトに入っているか。
新カテゴリを作ろうとしている場合（例：LLMO対策）は、まだ検索されていなくても**先行して計測を仕込む**。

## 提案フォーマット
```
【追加推奨プロンプト】
1. 「＿＿＿＿」｜段階：比較検討｜理由：主要競合Bとの一騎打ちが未計測
2. 「＿＿＿＿」｜段階：意思決定｜理由：ヒアリングで解約不安が受注障壁と判明
...
【見送り候補（優先度低）】
- 「＿＿＿＿」｜理由：検索ボリューム・商流との関連が薄い
```
