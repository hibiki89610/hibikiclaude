# LLMO無料分析 — 全体フロー（営業・CS向け）

クライアントに無料のLLMO診断レポート（pptx）を届けるまでの流れです。
作業のほとんどは **Claude Code との対話** で進みます。

```
[ヒアリング] → [登録フェーズ] → (ツールが計測) → [アウトプットフェーズ] → [納品]
 クライアント      Claude+ツール      数日〜          Claude+ツール         pptx送付
```

## 0. 準備（初回のみ）
1. Emma LLMOツール（https://emma-llmo-app-production.up.railway.app/）のアカウントをもらい、**自分のChromeでログイン**しておく
2. Claude（デスクトップアプリ or Claude Code）で、**このフォルダ（【公開版】LLMO無料分析）を開いて**セッションを始める
3. Claude in Chrome 拡張が入っていればベスト（Claudeが直接ツール画面を読めます）。無くてもスクショで代替可能

## 1. クライアントヒアリング
商談・CS面談で [02_ヒアリングシート.md](02_ヒアリングシート.md) の5項目を聞く。
特に重要なのは **②ブランド定義（AIに何者として覚えてもらいたいか）** と **⑤プロンプトの方向性**。
聞いた内容は `03_クライアントレポート/<クライアント名>/00_ヒアリング/` に保存（Claudeに渡せば整形・保存してくれます）。

## 2. 登録フェーズ（Claudeに依頼も可能だが、ツールに直接のほうが安全）
Claudeにこう言う：
> 「**登録フェーズ始めて**。クライアントは〇〇様」

Claudeがヒアリング確認 → ツール登録（サイトURL・ブランド定義・事業カテゴリ・競合）→ プロンプト候補の自動生成 → **追加すべきプロンプトの洗い出し** まで対話で進めます。
プロンプトはツール内で自動設計もできますが、**追加分は必ずClaudeとの案出し（ヒアリング内容ベース）→あなたの承認→ツール登録**の順で進みます。
ツールの「計測を実行」まで終われば登録フェーズ完了。計測データが溜まるのを待ちます。

## 3. アウトプットフェーズ（Claudeに依頼）
**前提：レポートのデータ（計測）はツール内で先に作っておくこと。** 計測データが無い場合、Claudeはレポート作成を中止して「計測を実行してから再依頼してください」と案内します（数値を推定で埋めることはありません）。

Claudeにこう言う：
> 「**〇〇様の無料分析レポート作って**」

Claudeは最初に、ツール左上の**クライアント／サイトの選択が対象と一致しているか**を確認してから読み取りを始めます。

Claudeがツールの4分析ページ（モニタリング／ブランドポジション／サイテーション／サイト診断）を読み、
分析 → レポートpptx生成 → 分析サマリー作成まで進めます。途中で分析結果の確認を求められるので、内容をチェックして返答してください。

## 4. 納品
- 完成物は `03_クライアントレポート/<クライアント名>/03_納品/` に入ります
- pptxをPowerPointで開いて最終確認（数値・クライアント名・誤字）
- そのままメール送付 or 商談で投影
