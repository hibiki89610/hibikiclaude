# トラブルシューティング

| 症状 | 対処 |
|---|---|
| Claudeがスキルを認識しない | このフォルダ（【公開版】LLMO無料分析）を開いた状態でセッションを始めているか確認。ダメなら「02_スキル・エージェント/llmo-free-report/SKILL.md に従ってレポートを作って」と直接指定 |
| Claude in Chromeがツールを開けない／ログイン画面になる | 自分のChromeでツールにログインしているか確認。解決しなければ [04_データ取得マニュアル.md](04_データ取得マニュアル.md) のB（スクショ or Gemini書き出し）へ切替 |
| ツールにログインできない | アカウント未発行の可能性。チーム管理者へ |
| `node: command not found`（pptx生成時） | Node.js未インストール。https://nodejs.org/ からLTS版を入れる（`node -v` で確認） |
| `Cannot find module 'pptxgenjs'` | `04_共通素材/エンジン` で `npm install` を実行（通常は node_modules 同梱済みで不要） |
| 日本語パスでエラー | パス全体を必ず `"…"` で囲む。それでも不安定ならフォルダ一式をローカル（例 `C:\llmo\`）にコピーして実行し、成果物だけ戻す |
| pptxのフォントが違う | PCに「Noto Sans JP」フォントを入れると設計どおりに表示（無くても開けます） |
| スライドの文字がはみ出す | specの文章が長すぎる。Claudeに「〇枚目の文章を短くして再ビルドして」と依頼 |
| Claudeが「計測データがありません」と停止する | 仕様です（データなしでレポートは作れません）。ツールの /monitoring で「計測を実行」→ 完了後に再依頼。登録がまだなら先に登録フェーズ |
| Claudeが「別のクライアントが選択されています」と確認してくる | 仕様です（取り違え防止）。対象クライアントで良いか答えれば、Claudeが切り替えて続行します |
| 計測データが古い | ツール側で「計測を実行」してから再取得。レポートには必ず計測日を明記 |
| 生成された数値が画面と違う気がする | `02_ワーク/データ取得メモ.md`（取得時の生データ）と画面を突き合わせ。相違があればClaudeに指摘して再生成 |

## 品質ルール（迷ったらこれ）
- 数値はツール実測のみ。作らない・盛らない
- メディア全リストは出さない（サンプルのみ）
- 対策はタスクまで書かない（方向性まで）
- 送付前にpptxを必ず人の目で最終確認
