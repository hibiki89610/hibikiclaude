# 新規クライアント用テンプレート

このフォルダをコピーして、名前を `03_クライアントレポート/<クライアント名>/` に変更して使います。
（Claudeに「登録フェーズ始めて」と言えば、コピーから自動でやってくれます）

| サブフォルダ | 入れるもの |
|---|---|
| `00_ヒアリング/` | ヒアリングシート（`01_マニュアル/02_ヒアリングシート.md` のコピーに記入）、登録メモ |
| `01_データ/` | ツール画面のスクショ／Gemini書き出しテキスト（Claude in Chromeが使える場合は空でOK） |
| `02_ワーク/` | Claudeの中間生成物（データ取得メモ・spec のコピーなど） |
| `03_納品/` | **クライアントに送る完成物**（レポートpptx・分析サマリー） |

クライアントに送ってよいのは `03_納品/` の中身だけです。
