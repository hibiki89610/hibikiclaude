# LLMO無料分析キット（公開版）

営業・CSメンバーが、クライアント向けの**LLMO無料診断レポート（EmmaToolsデザインのpptx）**を
Claudeとの対話で半自動生成するためのキットです。

- データ源：Emma LLMOツール（社内ツール）https://emma-llmo-app-production.up.railway.app/
- 作成日：2026-08-18 ｜ 管理：インハウスマーケ部
- 旧版（Dify CSV方式）：`../【過去作成】LLMO分析フロー_v3_共有用/`（参照用・更新停止）

## まず何をすればいい？
1. **[01_マニュアル/01_全体フロー.md](01_マニュアル/01_全体フロー.md) を読む**（5分）
2. Emma LLMOツールのアカウントをもらい、自分のChromeでログイン
3. Claude Code / Claudeデスクトップで**このフォルダを開いて**セッション開始
4. Claudeに話しかける：
   - 新規クライアントの登録 → 「**登録フェーズ始めて。クライアントは〇〇様**」
   - レポート作成 → 「**〇〇様の無料分析レポート作って**」

## フォルダ構成（触る目的別）
| フォルダ | 中身 | 誰がいつ触る |
|---|---|---|
| `01_マニュアル/` | 全体フロー・ヒアリングシート・ツール登録・データ取得・トラブル対応 | **全員**。最初と困ったとき |
| `02_スキル・エージェント/` | Claude用の作業指示書（SKILL.md）・分析の考え方・テンプレ | Claudeが読む。人は編集時のみ |
| `03_クライアントレポート/` | クライアントごとの作業フォルダと**納品物** | **全員**。案件ごと |
| `04_共通素材/` | pptx生成エンジン（Emmaデザイン）・完成サンプル | 触らなくてOK |

## 完成イメージ
`04_共通素材/サンプル/EmmaTools_LLMO無料分析_サンプル.pptx`（自社データで作った26枚の見本）
