# EmmaLLMOプロジェクト

このプロジェクトの資料を、**会社ごとにフォルダを分けて溜めていく**場所です。

```
EmmaLLMOプロジェクト/
├── お読みください.md      ← このファイル
├── カーセブン/            ← 会社ごとのフォルダ（自動で作られます）
├── EXIDEA/
└── …
```

## 会社フォルダは自動で作られます

初めての会社でも、フォルダを手で作る必要はありません。

```
カーセブンの資料作成して
```

と伝えれば、`projects/_TEMPLATE/` から `EmmaLLMOプロジェクト/カーセブン/` が自動で作られ、
そのまま資料作成が始まります。既にフォルダがあれば、そこに追加していきます。

## 会社フォルダの中身

```
<会社名>/
├── 00_ブリーフ/deck-brief.md          ← 誰に・何を（初回に記入。2回目以降は使い回し）
├── 01_データ/                         ← ★元ネタを放り込む場所
├── 02_ワーク/spec_<YYYYMMDD>.js       ← スライドのデータ定義（回ごとに残る）
└── 03_納品/<会社名>_<YYYYMMDD>.html   ← 完成物（回ごとに残る）
```

## 溜め込み方のルール

**同じ会社に2本目以降を作るときも、フォルダは分けません。** 日付で積み上げます。

- `01_データ/` … 元ネタは**日付を入れたファイル名**で置く（例：`モニタリング_20260901.csv`）
- `02_ワーク/` … `spec_20260901.js` のように日付つきで残す。過去回を上書きしない
- `03_納品/` … `カーセブン_20260901.html` のように日付つきで残す

こうしておくと、前回の資料を見ながら差分で作れます。
「前回と同じ構成で、数字だけ最新に」と伝えれば、前回のspecを下敷きにします。

## 01_データ に置けるもの

そのまま読めます：`.md` `.txt` `.csv` `.tsv` `.json` `.png` `.jpg`（スクショ）`.pdf`
Excel（`.xlsx`）は、シートをCSVに書き出して置くのが確実です。

**ここに置いたファイルとブリーフにある数字だけが資料に載ります。**
足りない数字を推測で埋めることはありません（不足として質問されます）。
