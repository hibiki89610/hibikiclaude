# 案件フォルダの使い方

このフォルダごとコピーして `projects/<案件名>/` にしてください。
`<案件名>` は英数字とハイフンを推奨します（例：`owned-media-proposal`）。

コピーしたら、Claudeに「**資料作成して**」と伝えるだけです。
フォルダ名を伝えると迷いません（例：「owned-media-proposal の資料作成して」）。

## 各フォルダの役割

| フォルダ | 中身 | いつ触るか |
|---|---|---|
| `00_ブリーフ/` | `deck-brief.md`（誰に・何を・どの事実で） | 最初に記入。空欄はClaudeが質問します |
| `01_データ/` | **元ネタを放り込む場所** | 資料の根拠になるファイルをここに置く |
| `02_ワーク/` | `spec.js`（スライドのデータ定義） | Claudeが作ります。直接編集も可 |
| `03_納品/` | 完成したHTML／PDF | 完成物の置き場所 |

## 01_データ に置けるもの

**そのまま読めます**：`.md` `.txt` `.csv` `.tsv` `.json` `.png` `.jpg`（スクリーンショット可）`.pdf`

**ひと手間必要**：Excel（`.xlsx`）は、シートをCSVに書き出して置くのが確実です。
そのまま置いた場合、Claudeが読めるかどうかは環境によります。

**ここに置いたファイルは、ブリーフより優先して読まれます。**
資料に載る数字は、ここにあるファイルとブリーフに実在するものだけです。
足りない数字をClaudeが推測で埋めることはありません（不足として質問されます）。

## 完成物の置き場所

```
03_納品/<案件名>_<YYYYMMDD>.html
```

Chromeで開いて `Ctrl/Cmd + P` →「PDFに保存」でスライドPDFになります。
