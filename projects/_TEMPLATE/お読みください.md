# 会社／案件フォルダのひな形

このフォルダは**コピー元**です。中身は編集せず、コピーして使ってください。

コピー先は2通りあります。

| 使い方 | コピー先 |
|---|---|
| プロジェクトの中の会社（推奨） | `projects/<プロジェクト名>/<会社名>/` |
| 単発の資料 | `projects/<案件名>/` |

**手でコピーする必要はありません。** Claudeに「**カーセブンの資料作成して**」のように
会社名を添えて伝えれば、フォルダが無ければ自動で作られ、そのまま資料作成が始まります。

## 各フォルダの役割

| フォルダ | 中身 | いつ触るか |
|---|---|---|
| `00_ブリーフ/` | `deck-brief.md`（誰に・何を・どの事実で） | 初回に記入。2回目以降は使い回し |
| `01_データ/` | **元ネタを放り込む場所** | 資料の根拠になるファイルをここに置く |
| `02_ワーク/` | `spec_<YYYYMMDD>.js`（スライドのデータ定義） | Claudeが作ります。回ごとに残ります |
| `03_納品/` | 完成したHTML／PDF | 回ごとに日付つきで溜まっていきます |

**2本目以降もフォルダは分けません。** 同じ会社フォルダの中に、日付つきで積み上げます。

## 01_データ に置けるもの

**そのまま読めます**：`.md` `.txt` `.csv` `.tsv` `.json` `.png` `.jpg`（スクリーンショット可）`.pdf`

**ひと手間必要**：Excel（`.xlsx`）は、シートをCSVに書き出して置くのが確実です。
そのまま置いた場合、Claudeが読めるかどうかは環境によります。

**ここに置いたファイルは、ブリーフより優先して読まれます。**
資料に載る数字は、ここにあるファイルとブリーフに実在するものだけです。
足りない数字をClaudeが推測で埋めることはありません（不足として質問されます）。

## 完成物の置き場所

```
03_納品/<会社名>_<YYYYMMDD>.html
```

Chromeで開いて `Ctrl/Cmd + P` →「PDFに保存」でスライドPDFになります。
