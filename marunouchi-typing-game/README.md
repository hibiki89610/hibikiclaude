# 丸ノ内線タイピングゲーム

東京メトロ丸ノ内線（池袋⇄荻窪、全25駅）をテーマにしたローマ字タイピングゲームです。
駅名を1駅ずつタイピングすると、路線図上の電車が1駅分前進します。

## 遊び方

`index.html` をブラウザで直接開くだけでプレイできます。追加のセットアップやパッケージインストールは不要です。

```
# 例（任意）: ローカルサーバー経由で開く場合
python3 -m http.server 8000
# その後ブラウザで http://localhost:8000/ にアクセス
```

- 画面に表示された駅名のローマ字をキーボードでそのまま入力してください（例：`ikebukuro`）。
- 1駅分入力し終えると「ぴろりんっ」という音とともに電車が次の駅へ進みます。
- 誤った文字は入力欄に反映されず、軽く画面が揺れます。
- 25駅目「荻窪」まで到達するとクリアです。タイム・ミスタイプ数・スコアが表示されます。
- 右上の「↔ 逆走行」ボタンで荻窪→池袋の逆順プレイに切り替えられます。
- 右上のスピーカーアイコンでミュートの切り替えができます。
- ベストタイムは `localStorage` に保存され、順走行／逆走行それぞれで記録されます。

## 技術構成

- ビルド不要の Vanilla HTML / CSS / JavaScript
- 効果音はすべて Web Audio API（`OscillatorNode`）でその場で合成生成しており、外部音源ファイルは使用していません
