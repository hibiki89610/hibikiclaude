# 記事トンマナ＆SEOレビューツール

Claude Codeを使った半自動の記事レビュー＆自動修正システムです。

## ディレクトリ構成

```
hibikiclaude/
├── config/
│   └── brand-rules.yaml      # ブランドルール設定（一度設定すればOK）
├── input/
│   └── article.md            # 記事入力用（都度編集）
├── output/
│   └── article-fixed.html    # 修正済みコード出力先
├── templates/
│   ├── review-prompt.md      # レビュー出力形式の定義
│   └── auto-fix-rules.md     # 自動修正ルール
└── README.md
```

## 機能一覧

| コマンド | 機能 |
|----------|------|
| `レビューして` | トンマナ/SEOチェック＆修正案提示 |
| `レビューして修正まで` | レビュー＋自動修正＋HTML出力 |
| `修正だけして` | レビュー省略で修正済みHTML出力 |

---

## 使い方

### STEP 1: ブランドルールを設定（初回のみ）

`config/brand-rules.yaml` を開き、以下を設定：

- 口調（ですます/だである）
- トーン（丁寧/カジュアルなど）
- 禁止表現・禁止ワード
- 文字作法（半角全角ルール）
- SEO要件

### STEP 2: 記事と情報を入力（都度）

`input/article.md` を開き、以下を入力：

1. **記事情報**（表形式）
   - 目的
   - ターゲットKW
   - 二次KW
   - 競合差分

2. **記事本文**
   - コードブロック内に貼り付け

### STEP 3: レビュー＆修正を実行

#### レビューのみ
```
レビューして
```

#### レビュー＋自動修正＋HTML出力（推奨）
```
レビューして修正まで
```

### STEP 4: 結果を受け取る

**レビュー結果**:
1. 総評（200字以内）
2. トンマナ逸脱リスト（表形式）
3. 読みやすさ改善（箇条書き）
4. SEO改善（箇条書き）
5. 重要度タグ（A/B/C）
6. 修正後サンプル文章（3箇所）

**修正済みHTML**:
- `output/article-fixed.html` に出力
- 修正ログも併せて表示

## 自動修正の対象

### 重要度A（必須修正）- 自動対応
| 項目 | 内容 |
|------|------|
| カギ括弧削除 | 「」を全て削除 |
| 問いかけ修正 | 〜ませんか？→平叙文に変換 |
| HTML構文修正 | 閉じタグ漏れ等を修正 |

### 重要度B（推奨）- 自動対応
| 項目 | 内容 |
|------|------|
| 長文分割 | 80字超の文を分割検討 |
| 表記統一 | brand-rules.yaml に従い統一 |

### 手動対応が必要
- SEO関連（タイトル、KW配置）
- コンテンツの追加・削除
- 画像alt属性の設定

## カスタマイズ

### 禁止ワードを追加する

`config/brand-rules.yaml` の `prohibited.words` に追加：

```yaml
prohibited:
  words:
    - "絶対"
    - "必ず"
    - "誰でも簡単に"
```

### 用語統一を設定する

`config/brand-rules.yaml` の `writing_rules.terms` に追加：

```yaml
writing_rules:
  terms:
    SEO: "seo, Seo"
    Webサイト: "WEBサイト, webサイト"
```
