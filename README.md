# 記事トンマナ＆SEOレビューツール

Claude Codeを使った半自動の記事レビューシステムです。

## ディレクトリ構成

```
hibikiclaude/
├── config/
│   └── brand-rules.yaml    # ブランドルール設定（一度設定すればOK）
├── input/
│   └── article.md          # 記事入力用（都度編集）
├── templates/
│   └── review-prompt.md    # レビュー出力形式の定義
└── README.md
```

## 使い方

### STEP 1: ブランドルールを設定（初回のみ）

`config/brand-rules.yaml` を開き、以下を設定：

- 口調（ですます/だである）
- トーン（丁寧/カジュアルなど）
- 禁止表現・禁止ワード
- 文字作法（半角全角ルール）
- SEO要件

### STEP 2: 記事と情報を入力（都度）

`input/article.md` を開き、以下を入力：

1. **記事情報**（表形式）
   - 目的
   - ターゲットKW
   - 二次KW
   - 競合差分

2. **記事本文**
   - コードブロック内に貼り付け

### STEP 3: レビュー実行

Claude Codeで以下のいずれかを入力：

```
レビューして
```

```
config/brand-rules.yaml と input/article.md を読んで記事をレビューして
```

### STEP 4: 結果を受け取る

以下の形式でレビュー結果が出力されます：

1. 総評（200字以内）
2. トンマナ逸脱リスト（表形式）
3. 読みやすさ改善（箇条書き）
4. SEO改善（箇条書き）
5. 重要度タグ（A/B/C）
6. 修正後サンプル文章（3箇所）

## カスタマイズ

### 禁止ワードを追加する

`config/brand-rules.yaml` の `prohibited.words` に追加：

```yaml
prohibited:
  words:
    - "絶対"
    - "必ず"
    - "誰でも簡単に"
```

### 用語統一を設定する

`config/brand-rules.yaml` の `writing_rules.terms` に追加：

```yaml
writing_rules:
  terms:
    SEO: "seo, Seo"
    Webサイト: "WEBサイト, webサイト"
```
