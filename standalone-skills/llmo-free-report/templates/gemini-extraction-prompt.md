# Gemini in Chrome 用データ抽出プロンプト

Claude in Chrome が使えない場合のフォールバック手順②。
ツールの各ページを**自分のChromeで開いた状態**で Gemini in Chrome（アドレスバー横のGeminiアイコン）を起動し、
以下のプロンプトを貼り付けて出力させ、結果をテキストファイルとして
`03_クライアントレポート/<クライアント名>/01_データ/` に保存してください。

ファイル名の例：`monitoring_20260818.txt`／`brand-listening_20260818.txt`／`citation-list_20260818.txt`／`site-audit_20260818.txt`

---

## ① /monitoring を開いた状態で

```
このページに表示されている内容を、省略せずテキストで書き出してください。
1) 上部4つのKPIカード：段階名（情報収集/ブランド想起/比較検討/意思決定）、指標名、数値、内訳（例：引用47/231）
2) 期間フィルタの選択状態と最終取得日時
3) ジャーニー別のプロンプト一覧：各プロンプト文と、ChatGPT/Gemini/AI Overviewsそれぞれの数値
   （引用率n/N、順位と言及率、勝率と勝敗数、ポジ率n/N。「圏外」「未計測」もそのまま）
表記は画面のまま、数値の丸めや解釈はしないでください。
```

## ② /brand-listening を開いた状態で

```
このページに表示されている内容を、省略せずテキストで書き出してください。
1) 上部の数値：最終計測日、意図どおりn/N、要対策n件、強めたい認識・抑えたい認識の数、方針/主要/全体の軸数
2) 「一覧」タブに切り替えて、認識軸ごとの状態（自社が主な勝者/接戦/競合が支配、強めたい/抑えたい）を軸名つきで
数値・軸名は画面のまま書き出し、解釈は加えないでください。
```

## ③ /citation-list を開いた状態で

```
このページに表示されている内容を、省略せずテキストで書き出してください。
1) 上部統計：掲載数（n/N媒体）、平均掲載順位、全URL数、アクション分類の件数（掲載依頼/順位改善/掲載(順位高)）
2) 一覧の上位10件について：Impact Score、アクション種別、URL、記事タイトル、媒体ドメイン、
   媒体種別（第三者媒体/競合）、ページ種類、AI別引用回数、自社の掲載状況（未掲載/掲載順位）、競合の掲載数、確認日
表記は画面のまま。URLは完全な形で書き出してください。
```

## ④ /site-audit を開いた状態で

```
このページに表示されている内容を、省略せずテキストで書き出してください。
1) 上部：クロール済みページ数、計測プロンプト数、診断済みページ数、平均スコア
2) スコア分布：S/A/B/C それぞれの件数と点数帯
3) ページ一覧をスコア昇順（要対応から）に並べ替えたときの下位15件：スコア、グレード、タイトル、URLパス、ページ種別
数値・タイトルは画面のまま書き出してください。
```

---

## スクショで渡す場合（フォールバック手順①）
Geminiを使わない場合は、各ページの**全体が入るスクリーンショット**（縦に長いページは分割可）を撮り、
`01_データ/` に `monitoring_1.png` のような名前で保存すればOKです。Claudeが画像から読み取ります。
