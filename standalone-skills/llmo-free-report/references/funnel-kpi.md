# ファネルKPIの読み方（/monitoring）

Emma LLMOツールはカスタマージャーニー4段階でKPIを持つ。レポートの「現状分析①」はこの4枚のカード。

| 段階 | KPI | 意味 | ツール表示例 |
|---|---|---|---|
| 情報収集 | **引用率** | 「選び方・相場」系の回答で、自社コンテンツがAIの参照元になった率 | `20%（引用 47/231）` |
| ブランド想起 | **言及率・平均順位** | 「おすすめは？」系の回答に自社名が出た率と、出たときの順位 | `35%（ブランド5位/50）` |
| 比較検討 | **勝率** | 「A vs B」でAIが自社を推した率 | `60%（151勝102敗）` |
| 意思決定 | **ポジ率** | 指名質問（料金・評判等）への回答がポジティブだった率 | `81%（非推奨1）` |

## 読み取りの型
1. **どの段階で落ちているか**を先に言う（例：想起以降は健闘、最上流の引用率が2割）。
2. 落ちている段階の**プロンプト群を見て原因仮説**を立てる：
   - 引用率が低い → 選び方・相場系コンテンツが無い/引用されない形式
   - 言及率が領域で割れる → 強い認識軸と圏外の認識軸がある（→ブランドポジションで詳述）
   - 勝率が相手で割れる → 誰に勝ち誰に負けるかを名指しで
   - ポジ率のうち特定テーマが低い → 公式情報の穴（料金・解約・著作権など）
3. AI別（ChatGPT/Gemini/AI Overviews）の差が大きければ一言添える。
4. **数値は必ず「取得日・期間」つきで**。前期間比があれば増減も。

## 注意
- KPIカードの値は期間フィルタ（直近1日/7日/30日/全期間）で変わる。**直近30日を標準**とし、レポートに期間を明記。
- 「未計測」のAI（Perplexity/Claude等）はレポートで触れない（対象：ChatGPT・Gemini・AI Overviews）。
