# AI Voice・自社エンティティ分析（AIは自社を「何者」と説明しているか）

SKILL STEP4・STEP5 の詳細。**AIが自社をどう認識・説明し、何を根拠（参照ソース）にしているか**を観測するモジュール。PDF「3つの声＝AI Voice」／実クライアントデッキ「AIが参照しているソースの特定」「競合の強み」に対応。すべて🔵【観測】が原則（推測は🟡に分離）。

---

## 1. 自社エンティティ観測（AIの中の"自社像"）

各エンジンに、指名系プロンプト（「〇〇とは？」「〇〇の特徴・評判は？」）を投げ、AIの説明を記録する。

観測項目：

| 項目 | 記録内容 |
|---|---|
| 定義 | AIは自社を「どんな会社/サービス」と言っているか |
| 用途・想起文脈 | どんな場面で名前が出るか（例：同人＝出る／販促＝出ない） |
| 語られる強み | AIが挙げる自社の強み（正しい？古い？） |
| 誤認・欠落 | 誤情報・古い情報・混同（別社と取り違え等） |
| 参照ソース | その説明の根拠にAIが挙げるURL（実在確認） |

**出力**：自社エンティティ観測表（エンジン別）。「AIにまだ伝わっていない自社の実態」を可視化 → デッキ「強み資産（AIにまだ伝わっていない）」の裏づけ。

---

## 2. クエリファンアウト → 参照ソース特定

AI回答は「AIの知識」ではなく「外部情報の要約」。**AIが根拠を探しに行く面**を特定する。

手順：
1. **サブクエリ展開**：重点プロンプトからAIが裏で同時に走らせる検索クエリ群を推定・列挙（メイン→サブ）。
2. **SERP収集**：各サブクエリの上位ページを取得し、繰り返し出る**媒体・URL**を洗い出す。
3. **最有力ソースの特定**：AI回答に頻繁に引用される比較メディアを特定（例：「印刷通販徹底比較 natuna.jp」）。実在確認。
4. **上位N社の書き出し**：そのメディアのランキング上位N社を列挙し、**自社の掲載有無**を判定。
5. **面の切り分け**：
   - 自社で動かせる面（公式・オウンド）
   - 第三者が強い面（比較メディア・アーンド）← AI引用の大半はここ（PDF：AI引用の84%はアーンド）

**出力**：
- 参照ソース特定表（最有力ソース／上位N社／自社掲載有無）
- **AI回答生成の仕組み図**（外部メディア → AI(要約) → ユーザー）※デッキ用の概念図
→ デッキ「AIが参照しているソースの特定」スライド。

## 3. 競合KBF抽出（AIが語る"選ばれる理由"）

注力プロンプトで上位常連の競合について、**AIが言及する強み（KBF＝比較の判断軸）**を抽出する。

出力＝**競合の強みマトリクス**：

| 順位傾向 | 事業者名 | AIが言及する強み（KBF） |
|---|---|---|
| 1位常連 | ラクスル | 知名度、テンプレ豊富、初心者向け、価格 |
| 上位常連 | プリントパック | 業界最大手、低価格、大ロット対応 |
| 登場せず | 自社 | —（★ここが課題） |

- KBFは**自社が言いたいこと**ではなく**AIが実際に語っている軸**を起点にする。
- 抽出したKBFに対し、自社の証拠（RTB）の過不足をSTEP7でギャップ化する。
→ デッキ「注力プロンプトで上位常連の競合」スライド。

---

## 4. 意図しない推奨のチェック

- 本来狙わない用途・セグメントで推奨されていないか（例：BtoC想定なのに個人向け文脈でだけ出る）。
- 不利な文脈・否定的文脈で名前が出ていないか。
- これらは是正対象として🟡【推定】で戦略に反映。
