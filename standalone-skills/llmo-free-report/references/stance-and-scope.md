# 当社スタンスと無料版スコープ

## 当社のLLMOの考え方（レポート01章・固定8枚の骨子）
- 生成AIは情報インフラになった（利用率・購買関与の市場データ）
- AIは第三者情報を強く参照する＝自社サイト改善だけでは動かない
- AI推奨後、顧客は“後から”指名検索で訪れる＝LLMO×SEO×CVの一貫設計
- CEP → KBF → 参照先 → RTB で逆算／引用は数でなく役割／3つの声（Company・User・Digital）の一致／着手は必ず診断から
- 支援は3フェーズ9工程。**本無料分析は PHASE 1（診断）に相当**

## 観測🔵と推定🟡の分離（品質の生命線）
- 🔵観測＝Emma LLMOツールの実測値（KPI・順位・掲載状況・スコア）。計測日を必ず明記
- 🟡推定＝ヒアリング差分・所見・対策の方向性などClaudeの分析・提言
- すべてのスライド脚注でどちらかを明示する。混ぜない。数値の創作は絶対にしない

## 無料版のスコープ（やること／やらないこと）
| | 無料版でやる | 無料版ではやらない（＝有償） |
|---|---|---|
| 計測 | 限定本数のプロンプト（20〜40本目安） | プロンプト拡張・継続モニタリング |
| サイテーション | 可能性の総量＋サンプル3〜4件 | 優先度付き全メディアリスト |
| 対策 | 方向性4つまで | タスク設計・実行手順・実行伴走 |
| サイト診断 | 分布と傾向の要約 | ページ別の具体的改善指示 |

## ご支援メニュー（レポート06章・固定）
1. **LLMOコンサルティング（月60万円〜）**：詳細タスク設計〜実行伴走（メディア掲載交渉・コンテンツ整備・構造化・月次モニタリング）
2. **ツール契約（要お見積り）**：モニタリング等の部分機能を自社運用で
3. **レポーティング＋助言（月1回）**：本レポート形式の定期レポート＋改善助言のみの契約
4. **補足（ブランド支援）**：LLMOはブランド定義が起点。定義から見直す場合は **CEP分析・n1分析・カテゴリコンセプト開発** などのご支援も可能
