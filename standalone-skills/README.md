# LLMO資料作成キット — claude.ai Skills版

`【公開版】LLMO無料分析/` に入っているキットは、Claude Codeがこのリポジトリをプロジェクトとして開いたときにだけ
`CLAUDE.md` 経由で機能する。Claude in Chrome（claude.aiの通常チャットからブラウザ操作する機能）はこのリポジトリの
`CLAUDE.md` を読み込まないため、「資料作成して」と言っても意図どおりに動かないことがある
（クライアント名を聞く代わりに「資料形式はどれにしますか？」のような汎用の質問が返ってくる、など）。

このフォルダは、その2つのスキルをclaude.aiのアカウントに**Skillとして直接登録**できる形にパッケージし直したもの。
アカウントに登録すれば、Claude in Chromeを含めどのセッションからでも、このリポジトリを開かずに動作する。

## 中身

- `llmo-free-report/` — 「資料作成して」等で起動するレポート作成スキル（pptx生成エンジン同梱）
- `llmo-registration/` — 「登録フェーズ」等で起動する、ツールへのクライアント新規登録スキル

どちらも `02_スキル・エージェント/` 配下の元の内容をベースに、外部フォルダに依存しない自己完結型に書き直している。
実クライアントの機密データ（`03_クライアントレポート/`配下）は含めていない。

## インストール方法

1. `llmo-free-report.skill` と `llmo-registration.skill`（このリポジトリには含めていない配布用ファイル。
   Claudeとのセッションで `python -m scripts.package_skill <このフォルダ内のスキル名>` を実行するか、
   セッションから直接ファイルとして受け取る）を用意する
2. claude.ai の 設定（Settings） → Capabilities → Skills を開く
3. 「Upload skill」で各 `.skill` ファイルをアップロードする
4. 有効化すれば、Claude in Chromeを含む対話で「資料作成して」「登録フェーズ始めて」等の発話がこのスキルを呼び出す

## 更新のしかた

`【公開版】LLMO無料分析/02_スキル・エージェント/` 側の元の内容（ルール・料金・手順）が更新されたら、
このフォルダの該当ファイルにも反映し、`.skill` を作り直してclaude.aiに再アップロードする（同名でアップロードすれば上書きされる）。
