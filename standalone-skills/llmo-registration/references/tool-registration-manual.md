# Emma LLMOツール 登録マニュアル（手動で行う場合）

登録はClaudeの登録フェーズスキル（llmo-registration）が案内しますが、自分で操作する場合の手順です。
URL：https://emma-llmo-app-production.up.railway.app/ （要ログイン）

## 1. クライアントとサイトの追加
1. 左上ヘッダのプルダウン →「＋ クライアントを追加」
2. 「＋ サイトを追加」→ サイト設定（/settings）が開く

## 2. サイトの基本情報
| 項目 | 入れるもの | ヒアリング対応 |
|---|---|---|
| サイトURL | トップページURL（配下はsitemapで自動取得） | ① |
| サイト名 | 正式サイト名 | ① |
| ブランド名 | AIに認識させたい正式表記（表記ゆれ統一の基準） | ② |
| 業種 | プルダウンから選択 | — |
| 事業カテゴリー | カテゴリ＋軸キーワード（「＋事業カテゴリーを追加」で複数可） | ③ |
| サイト説明 | AIに渡す一言説明 | ② |
| ブランド定義 | 「AIに何で覚えてもらいたいか」の文章。**「URLから自動生成」→ヒアリング②で必ず上書き・追記** | ② |

→「基本情報を保存」

## 3. 競合の登録
サイト設定内の競合欄にヒアリング④の競合を登録。

## 4. プロンプトの生成と追加
1. ブランド定義欄の「**この定義から推奨プロンプトを抽出 →**」で候補を自動生成
2. 自動候補で足りない分は、Claudeの**プロンプト洗い出し**（登録フェーズSTEP3）で追加候補を出してもらい、採用分をプロンプト編集画面（/settings#section-prompt）から追加
3. **無料分析は合計20〜40本目安**。入れすぎない

## 5. 計測の実行
モニタリング画面（/monitoring）右上の「計測を実行」。完了すると各KPIに数値が入ります。
サイト診断は /site-audit の「診断を実行」（サイト全体クロール）。

## 注意
- ツールのアカウント・ログイン情報はチーム管理者から個別に受け取ること（共有チャットに書かない）
- 既存クライアントの設定を書き換えない（自分の担当クライアントのみ操作）
