# ファクトチェック自動修正ルール

ファクトチェック後の自動修正を行う際のルールを定義します。

## 実行方法

```
ファクトチェックして修正まで
```

---

## 自動修正対象（リスク高：必須修正）

### 1. 未検証の断定表現を緩和

**変換パターン**:
| 変換前 | 変換後 |
|--------|--------|
| 〜です。 | 〜とされています。 |
| 〜になります。 | 〜になるとされています。 |
| 〜が必要です。 | 〜が必要とされています。 |
| 〜できます。 | 〜できるとされています。 |
| 〜となっています。 | 〜となっているとされています。 |

**適用条件**: 出典が不明かつリスク「高」の主張のみ

### 2. 最上級・絶対表現の緩和

**変換パターン**:
| 変換前 | 変換後 |
|--------|--------|
| 最も〜 | 〜の一つとして |
| 唯一の〜 | 主要な〜の一つとして |
| 必ず〜 | 多くの場合〜 |
| 絶対に〜 | 基本的に〜 |
| 100%〜 | ほぼ〜/多くの場合〜 |
| 全ての〜 | 多くの〜 |
| 誰でも〜 | 多くの人が〜 |

### 3. 数値の曖昧化（出典不明の場合）

**変換パターン**:
| 変換前 | 変換後 |
|--------|--------|
| ◯◯万人 | 約◯◯万人/◯◯万人以上 |
| ◯◯% | 約◯◯%/◯◯%程度 |
| ◯◯円 | 約◯◯円/◯◯円前後 |

**出典追記テンプレート**:
```
〜（◯◯年時点/◯◯調べ）
```

### 4. 因果関係の緩和

**変換パターン**:
| 変換前 | 変換後 |
|--------|--------|
| 〜すると〜になる | 〜すると〜になる可能性がある |
| 〜の原因は〜です | 〜の原因の一つとして〜が挙げられます |
| 〜によって〜が起こる | 〜が〜に影響を与えることがあります |
| 〜すれば必ず〜 | 〜することで〜が期待できます |

---

## 自動修正対象（リスク中：推奨修正）

### 5. 伝聞・推量表現の追加

**追加パターン**:
- 文末に「〜と言われています」
- 文末に「〜という見方があります」
- 文頭に「一般的に」「多くの場合」

### 6. 条件・範囲の明示

**追加パターン**:
- 「〜の場合は」を追加
- 「〜においては」を追加
- 「〜によっては」を追加

### 7. 出典プレースホルダーの挿入

**挿入パターン**:
```
〜（※要出典確認）
〜（出典：[要追記]）
```

---

## 修正しない項目

以下は自動修正の対象外とし、手動確認を推奨：

1. **法律・規制関連の記述**
   - 法令名、条文番号、罰則内容
   - 理由：正確性が極めて重要、専門家確認必須

2. **医療・健康関連の記述**
   - 効果、効能、副作用、治療法
   - 理由：薬機法抵触リスク、専門家確認必須

3. **企業・製品の固有情報**
   - 価格、スペック、サービス内容
   - 理由：公式情報との照合が必要

4. **人物の経歴・発言**
   - 本人確認が必要な情報
   - 理由：名誉毀損リスク

5. **歴史的事実**
   - 年号、出来事の詳細
   - 理由：学術的検証が必要

## 修正後コード出力形式

修正後のHTMLは、以下のようにコードブロックで画面上に直接表示する：

~~~
```html
（修正後のHTML全文をここに出力）
```
~~~

**重要**: ファイル出力ではなく、画面上にコードブロックで表示すること。
ユーザーがコピペできる形式で提供する。

- 〜が指摘されています

- 〜と言われています
- 〜みたいです
- 〜のようです
- 〜かもしれません
- 〜という話もあります

**専門的（論文/レポート調）**:

- 〜という研究結果があります
- 〜と推察されます

- 〜というエビデンスがあります
