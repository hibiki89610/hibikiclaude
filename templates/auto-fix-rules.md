# 自動修正ルール

このファイルは、トンマナ逸脱を自動修正するためのルールを定義します。

## 実行コマンド

Claude Codeで以下のように指示：

```
レビューして修正まで
```

または

```
記事を修正して output/article-fixed.html に出力して
```

---

## 自動修正対象（重要度A：必須修正）

### 1. カギ括弧「」の削除

**ルール**: 「」で囲まれたテキストからカギ括弧を削除

**変換例**:
- 「選ばれる存在」 → 選ばれる存在
- 「何から始めればいいか分からない」 → 何から始めればいいか分からない

**例外**:
- 引用元の正式名称（書籍タイトル等）は残す場合あり
- ユーザーが明示的に残すよう指示した場合

---

### 2. 問いかけ・投げかけ表現の修正

**ルール**: 疑問形・同意を求める表現を平叙文に変換

**パターンと修正例**:

| パターン | 修正前 | 修正後 |
|----------|--------|--------|
| 〜ませんか？ | 課題を抱えていませんか？ | 課題を抱える企業が増えています。 |
| 〜でしょうか？ | 〜ではないでしょうか？ | 〜と考えられます。 |
| 〜ですよね | 変わりますよね。 | 変わります。 |
| 〜と思いませんか？ | 重要だと思いませんか？ | 重要です。 |
| 〜ではありませんか？ | 必要ではありませんか？ | 必要です。 |

---

### 3. HTML構文エラーの修正

**ルール**: 閉じタグ漏れ、タグの入れ子エラーを修正

**チェック項目**:
- `<p>` タグの閉じ忘れ
- `<div>` タグの閉じ忘れ
- `<ul>`, `<ol>` 内の `<li>` タグ
- `<table>` 内の構造

---

## 自動修正対象（重要度B：推奨）

### 4. 長文の分割

**ルール**: 80字を超える一文は分割を検討

**方法**:
- 「〜が、」「〜ので、」「〜ため、」で分割
- 主語が変わる箇所で分割

---

### 5. 表現の統一

**ルール**: brand-rules.yaml の terms に従って表記を統一

**例**:
- WEBサイト → Webサイト
- seo → SEO
- ユーザ → ユーザー

---

## 出力形式

修正後のHTMLは以下の形式で出力：

```
output/
└── article-fixed.html    # 修正済み本文（HTMLタグ付き）
```

---

## 修正ログの出力

修正時に以下の情報を表示：

```
## 修正ログ

| # | 修正箇所 | 修正前 | 修正後 | ルール |
|---|---------|--------|--------|--------|
| 1 | 〜 | 〜 | 〜 | カギ括弧削除 |
| 2 | 〜 | 〜 | 〜 | 問いかけ修正 |
...

合計: ○箇所を修正しました。
```

---

## 修正しない項目

以下は自動修正の対象外（手動確認が必要）:

- SEO関連（タイトル、見出し、KW配置）
- コンテンツの追加・削除
- 構成の変更
- 画像alt属性の設定
- 内部リンクの追加
